# cihangwang2.github.io

Personal academic website of Cihang Wang, served by GitHub Pages.

Plain HTML/CSS, no build step. Edit `index.html`, `research.html`, `teaching.html` and `style.css` directly; push to `main` and GitHub Pages redeploys within a minute or two.

- `index.html` – home page (bio, portrait, contact links)
- `research.html` – working papers, publications, work in progress (abstracts use `<details>` so they expand on click)
- `teaching.html` – courses, awards, lecture notes
- `assets/` – banner and portrait images
